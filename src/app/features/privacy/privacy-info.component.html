01 · INFORMACIÓN

Qué información utiliza FinFlow

Datos de cuenta, como nombre y correo electrónico, y los registros financieros que tú ingresas: ingresos, gastos, categorías, presupuestos, cuentas y metas. También se utilizan datos técnicos de autenticación y seguridad para gestionar el acceso.

02 · FINALIDAD

Para qué se utiliza

Para que puedas iniciar sesión, consultar y gestionar tus finanzas, visualizar estadísticas y mantener la seguridad de tu cuenta. No deberías tener que aceptar publicidad para usar las funciones financieras.

03 · SEGURIDAD

Controles que ya existen

Las conexiones públicas utilizan HTTPS; el backend autentica solicitudes con JWT y comprueba permisos de acceso. Las contraseñas se verifican mediante hashes BCrypt. Esto no significa que todos los datos estén cifrados de extremo a extremo.
